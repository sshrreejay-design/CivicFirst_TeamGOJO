
# CivicFirst — Where Should We Fix First?

## About the Project
CivicFirst is an evidence-based city prioritization system that analyzes civic issue data to identify which locations need attention first. It uses data-driven scoring, rankings, and visualizations to support transparent and informed urban decision-making.

## Problem Statement
Cities face multiple civic issues, but limited resources make it difficult to decide which problems should be addressed first.

## Our Solution
CivicFirst helps prioritize civic issues using data analysis and visual insights, enabling users to compare locations and identify high-priority problems.

## Key Features
- Civic issue data analysis
- Priority scoring and ranking
- Interactive dashboard
- Data visualization
- Evidence-based decision support

## Technology Stack
- HTML
- CSS
- JavaScript
- CSV Dataset
- GitHub Pages

## How to Run
1. Open the deployed website.
2. Upload or load the available civic issue dataset, if supported.
3. Explore issue rankings and visualizations provided by the application.
